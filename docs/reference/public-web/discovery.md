# Metadata discovery frontend

Routes: /hotels and /hotels/[slug], matching the inspected archive. Next server reads API_ORIGIN/api/v1/public/hotels, discovery-options and hotels/{slug}; no-store fetches and force-dynamic pages. No credentials forwarded to public reads. API_ORIGIN is server-only. Missing backend returns an explicit unavailable/retry state, never reference or synthetic listings.

Wire source: Catalog owner's PublicHotelController and PublicHotelResource metadata-only contract. Public fields id,slug,name,description,property_type,city,country,photo:null. Options {data:{property_types:[{key,label}],capabilities}}; detail {data:hotel}; Laravel list {data:hotel[],meta:{current_page,last_page,total,per_page,...}}. Backend owns administrator-approved snapshot/release/withdrawal, classification and source truth. No real source release is authorized by this frontend work.

PO explicitly approved interim Name A–Z (sort=name). Name search is literal property-name search, not destination/availability search. Types OR within the selected set, supplied by the options endpoint rather than duplicated client taxonomy. Canonical local query URLs use sorted/deduplicated property_types[] keys; page1 is omitted and filter changes reset pagination. Repeated scalars, unknown/legacy parameters, unsupported sorts, invalid page bounds or unavailable type choices get explicit recovery; never silently substitute recommended order or broaden their result set. Tracking query keys are not sent to the API. No date/price/star/occupancy filters until backed by approved data.

Filters use a native modal with Apply/Cancel/reset-to-applied behavior. Active chips remove individual filters; search URLs survive refresh and Back. FreshLink uses Next Link without prefetch and full-origin navigation to avoid replaying client-router snapshots. A persisted browser history restore reloads from origin. Subsequent reads must omit withdrawn listings; already disclosed content cannot be recalled. Unknown/withdrawn detail has a not-found state. No private images or shared optimizer cache enter this metadata slice; neutral 'Photo not available' is intentional.
